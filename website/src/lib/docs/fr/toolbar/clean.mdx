# <SquareDashedMousePointer size="24" class="inline-block" style="margin-bottom: 5px" /> { title }

Lorsque l'outil de nettoyage est sélectionné, glisser le curseur sur la carte avec le bouton droit de la souris, ou avec un doigt sur un écran tactile, crée une sélection rectangulaire. Le bouton gauche de la souris continue de déplacer la carte.

Selon les options sélectionnées dans la boîte de dialogue illustrée ci-dessous, cliquer sur le bouton de suppression supprimera les points GPS et/ou [points de passage](../gpx) situés à l'intérieur ou à l'extérieur de la sélection.
