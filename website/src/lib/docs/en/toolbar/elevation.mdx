# <MountainSnow size="24" class="inline-block" style="margin-bottom: 5px" /> { title }

This tool allows you to add elevation data to traces and [waypoints](../gpx), or to replace the existing data.

<div class="flex flex-row justify-center">
    <Elevation class="text-foreground p-3 border rounded-md shadow-lg" />
</div>

**Clear elevation data** removes all elevation data from the selection, including the waypoint elevations when a whole file is selected.

<DocsNote>

Elevation data is provided by <a href="https://mapterhorn.com" target="_blank">Mapterhorn</a>.
You can learn more about its origin and accuracy in the <a href="https://mapterhorn.com/attribution/" target="_blank">documentation</a>.

</DocsNote>
