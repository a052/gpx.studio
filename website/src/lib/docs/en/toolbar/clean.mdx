# <SquareDashedMousePointer size="24" class="inline-block" style="margin-bottom: 5px" /> { title }

When the clean tool is selected, dragging on the map with the right mouse button, or with one finger on a touch screen, will create a rectangular selection. The left mouse button still pans the map.

Depending on the options selected in the dialog shown below, clicking the delete button will remove GPS points and/or [waypoints](../gpx) located either inside or outside the selection.
