# <SquareDashedMousePointer size="24" class="inline-block" style="margin-bottom: 5px" /> { title }

使用该工具时，按住鼠标右键在地图上拖拽（触摸屏可用单指拖动）可创建矩形选区。鼠标左键仍可用于平移地图。

在下方对话框中，选择要删除的要素（GPS 点或 [标注点](../gpx)），以及作用范围（选取内部或外部）。
