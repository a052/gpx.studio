# <SquareDashedMousePointer size="24" class="inline-block" style="margin-bottom: 5px" /> { title }

Wenn das Bereinigungswerkzeug ausgewählt wurde, erzeugt das Ziehen mit der rechten Maustaste, oder mit einem Finger auf einem Touchscreen, eine rechteckige Auswahl. Mit der linken Maustaste wird die Karte weiterhin verschoben.

Abhängig von den Optionen, die im unten gezeigten Dialogfeld ausgewählt wurden, werden durch Klicken auf die Schaltfläche "Entfernen" GPS-Punkte und/oder [Wegpunkte](../gpx) entfernt, die sich entweder innerhalb oder außerhalb der Auswahl befinden.
