[Wegpunkte](../gpx) können zu GPX-Dateien hinzugefügt werden, um Orte von Interesse auf der Karte zu markieren und sie auf deinem GPS-Gerät anzuzeigen.

### Wegpunkte erstellen

Um einen Wegpunkt zu erstellen, füllen Sie das untenstehende Formular aus.
Sie können den Ort des Wegpunktes entweder durch Klicken auf die Karte oder durch manuelle Eingabe der Koordinaten auswählen.
Überprüfen Sie das Formular, wenn Sie fertig sind.

<div class="flex flex-row justify-center">
    <Waypoint class="text-foreground p-3 border rounded-md shadow-lg" />
</div>

### Einen Wegpunkt bearbeiten

Das obige Formular kann auch verwendet werden, um einen bestehenden Wegpunkt zu bearbeiten, nachdem er auf der Karte ausgewählt wurde.
Wenn Sie den Wegpunkt nur verschieben möchten, können Sie ihn an den gewünschten Ort ziehen.
