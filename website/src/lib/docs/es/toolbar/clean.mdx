# <SquareDashedMousePointer size="24" class="inline-block" style="margin-bottom: 5px" /> { title }

Al seleccionar la herramienta limpiar, si arrastra sobre el mapa con el botón derecho del ratón, o con un dedo en una pantalla táctil, creará una selección rectangular. El botón izquierdo del ratón sigue desplazando el mapa.

Dependiendo de las opciones seleccionadas en el diálogo que se muestra a continuación, hacer clic en el botón de borrar eliminará los puntos GPS y/o [puntos de ruta](../gpx) ubicados dentro o fuera de la selección.
